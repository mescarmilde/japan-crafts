## 1. 概要

有田焼は、佐賀県西松浦郡有田町とその周辺を中心に生産される**磁器**。白い素地、染付、色絵など多様な装飾を持ち、特定の色や一つの様式に限定されない。江戸期の流通・鑑賞では「伊万里」「肥前」などの名が用いられ、「有田焼」という呼称の普及は明治以降と説明される。[S01]

現在の一般的な産地名「有田焼」、国の伝統的工芸品の名称「伊万里・有田焼」、歴史研究の「肥前磁器」は範囲が一致しない。組合は伊万里・有田・嬉野の窯元を含む。現代の波佐見焼・三川内焼を、歴史上の「伊万里」に含まれたという理由だけで有田焼にまとめない。個々の商品は製造者・生産地表示を確認する。[S02・S03・S13]

**記事の導入方針**：有田を「日本の初期磁器生産の中心地で、現在も製造・絵付け・販売の仕事が集まる町」と位置づける。豪華な金彩品だけでなく、染付の日常食器や現代の白磁も視野に入れる。[S01・S03・S36]

## 2. 起源

### 年代と技術移転

有田では磁器に先行して陶器生産が行われ、初期には陶器と磁器を併焼する窯があった。磁器の成立は**1610年代**と表現するのが慎重である。「1616年」は産地の創業記念年として重要だが、その年に一斉に磁器産業が完成したという意味ではない。[S04・S05]

豊臣秀吉による朝鮮侵略・出兵後、朝鮮半島の陶工が諸大名によって日本へ連れてこられたことが、肥前の窯業技術の展開に関わる。自発的な海外就職のような「技術交流」だけで記述せず、戦争に伴う移動・連行の背景を明記する。一方、各人物の渡航事情を一律に推定しない。[S01・S04]

### 李参平（金ヶ江三兵衛）

**伝統的説明**：李参平が1616年に泉山陶石を発見し、日本で最初の磁器を焼いたという物語は、佐賀県の産業紹介や窯の伝承に見られる。[S02・S06]

**史料・研究の留保**：有田町資料館は、金ヶ江家関係の1616年の記録を「有田への移住」に関わるものと整理し、発明・泉山発見の同時証明とはしない。初期の西部窯場と泉山の距離、出土品の年代も、単純な創業物語を再検討する根拠になる。[S05]

さらに天狗谷窯の成立を1630年代初めとみる研究から、泉山の発見・本格利用を1630年前後に置く解釈が提示されている。これは発見日を記録した文書ではなく、窯の年代などからの推定。業界団体の現行解説も、1616年の磁器開発と1630年前後の泉山発見・産業化を分けている。[S07・S03]

**執筆判断**：「李参平は陶祖として顕彰される重要人物。ただし日本磁器の成立を、一人の発明と一日付で説明できるわけではない」とする。百婆仙ら他の朝鮮人陶工集団や既存の陶器生産を含める。個人別の技術上の貢献量は未確定。[S08]

## 3. なぜ有田だったのか

### 複数条件の組合せ

| 条件 | 生産にどう結びつくか | 留保・出典 |
| --- | --- | --- |
| 泉山陶石 | 流紋岩が熱水変質した原料資源。大量の磁器生産を支える採掘拠点となった | 陶石の存在と初期磁器の成立年を同一視しない。[S07・S09] |
| 原料を使える状態にする知識 | 採石だけでなく粉砕、選別、水簸、陶土の調整が必要 | 石を見つければ直ちに器になるわけではない。[S10・S30] |
| 水 | 原料処理に加え、唐臼で陶石を砕く動力となる | 川の流量だけでなく堰を設ける条件も重要。渇水もあり「常に水が豊富」は不適切。[S05・S10・S40] |
| 森林・薪 | 高温焼成を支える燃料 | 森林は無尽蔵ではなく、窯の増加が資源圧力を生んだ。[S11・S12] |
| 谷・斜面 | 登り窯、原料・水・薪の近接、集落のまとまりを考える手がかり | 谷ならどこでも磁器産業が成立するわけではない。個別窯の立地比較が必要。[S10・S14] |
| 藩の制度 | 窯場、原料、職人、出入りを管理し、特定地域へ生産を集中 | 保護政策と就業制限・排除の両面がある。[S11・S14] |
| 職人の集積 | 陶工に加え、原料・成形・焼成・上絵・販売の仕事が連結 | 百婆仙らの移住と東西の生産構成の変化をあわせて見る。[S08・S15] |
| 伊万里・長崎への接続 | 内陸の窯場を沿岸輸送・海外貿易へつなぐ | 有田は海港ではなく、伊万里までは陸上輸送が必要。[S16・S17・S18] |

**地理上の要点**：有田は九州北西部、佐賀藩領の内陸に位置し、近隣の同藩の港・伊万里津へ荷を運べた。ただし「窯から船まで自然に川を下った」という説明は避ける。資料館は人力や馬による陸路を説明し、上手路・下手路や荷担いの記憶を紹介している。[S16・S17]

**編集上の仮説**：有田の強みは、陶石という資源だけでなく、資源を磁器へ変える技能と、その技能を集積・維持する制度、完成品を市場へ運ぶ経路が結びついたこと。さらに国内外からの需要が、量と品質の両方の改善を促したと考えられる。これは資料をつないだ総合的説明で、単一史料に書かれた「成立原因」ではない。[S07・S10〜S18]

## 4. 有田と伊万里

| 用語 | 主に何を指すか | 英語記事での扱い |
| --- | --- | --- |
| Arita Ware／有田焼 | 有田を中心とする産地名 | 現在の記事の主題。特定の装飾様式に限定しない |
| Imari Ware／伊万里焼（歴史的用法） | 伊万里津からの流通と結びついた肥前磁器の呼称 | 有田産を多く含むが、必ずしも有田産だけではない |
| 伊万里焼（現代の産地表記） | 伊万里市などで作る磁器という用法もある | 江戸期の広域流通名と区別する |
| Ko-Imari／古伊万里 | 江戸期の肥前磁器を広く指す用法。範囲に差がある | 赤・青・金の金襴手だけと定義しない。展示・収集分類の文脈を示す |

伊万里市の解説は、古伊万里の生産地に有田、塩田、波佐見、三川内などを含め、主に1610年代から江戸末期、場合によって明治期までを対象とする。したがって「有田で作り、伊万里港から出したのでImariと呼ばれた」は**入口としては正しいが、範囲を狭めすぎる説明**である。[S13]

伊万里は国内流通にも関わる名前であり、「海外だけの呼称」ではない。また海外貿易の窓口は長崎。九州国立博物館は1659年の有田磁器を積んだVOC船の**長崎出帆**を記す。伊万里港からヨーロッパへ直航したかのような図にしない。すべての時期・全製品が同じ輸送経路だったとも断定しない。[S13・S16・S18]

## 5. 江戸時代の産業

### 管理・集積・その代償

1637年の窯場再編では、森林資源の保護を背景とする説明とともに、826人の陶工の排除が記録される。資料によって競争調整を示唆する説明もあり、「環境保護だけの政策」とは断定しない。また定住した朝鮮人陶工とその子孫などを扱う規定があり、「朝鮮人を一律に追放した」とする読みは誤り。[S11・S12]

内山には出入りを管理する口屋が置かれ、原料や技術・人の流出を制限した。藩は生産を保護するだけでなく、許可と監督によって産業を統制した。「秘密が完全に守られた」証明ではなく、流出を防ごうとする制度の存在として記す。[S14]

### 分業

素地を作り焼く窯焼き、上絵を施す赤絵屋、商品を扱う商人などが関わり、工程・職種ごとに集積した。原料から販売まで一人が完結する現代的な「陶芸家」の像だけでは説明できない。赤絵町や商人の町など、都市の構成自体に分業が表れる。[S14・S15]

「有田千軒」は繁栄した窯業都市を捉える呼称として使い、常に正確に千戸だったという統計にはしない。窯元数・赤絵屋数・窯の基数・行政上の「山」の数も別の単位。時期を示さず数字を並べない。[S14・S15]

**理解の枠組み**：原料供給→成形・焼成→上絵→商人→輸送→市場、という仕事の連鎖を中心にする。ただし時代・経営体により兼業や分業の範囲は変わる。近代以降の自由営業や企業化を、そのまま江戸初期へ投影しない。[S01・S14・S15]

## 6. 海外輸出

### 中国との関係

初期有田磁器は中国磁器の形や文様を参照した。九州国立博物館の初期伊万里の作品解説も、中国由来の山水文・如意頭文を指摘する。朝鮮半島からの技術移転と、中国製品を目標とした商品づくりは、別の要素として説明できる。[S19]

明清交替前後の戦乱と清の海禁・遷海政策は、中国磁器の海外供給を困難にし、日本磁器への注文が増える背景になった。しかし1644年に中国の全窯・全輸出が一斉に止まったわけではない。1684年の海禁解除後には輸出が本格化し、有田は再び中国製品と競争する。研究資料は海禁期にも中国磁器の輸出が完全停止ではなかった点を指摘する。[S20・S21]

注意：S21の研究報告PDFは検索で該当本文を確認できたが、直接取得は429エラーだった。全章の精読は未了。正確な航路別・年代別数量を記事に載せる前に再取得する。野上建紀「清朝の海禁政策と陶磁器貿易」（2015）も追加精読候補。[S22]

### VOCと市場

有田磁器の海外輸出は1650年代に展開し、**1659年はヨーロッパ向け輸出の本格化を示す重要年**。それを日本磁器が初めて海外へ出た年と一律に定義しない。VOCは主要な担い手だが、日本磁器の全海外交易をVOCだけに還元しない。[S01・S18・S21]

輸出先はヨーロッパだけでなく東南アジアなどを含む。欧州向けでは、食器・酒器に加え、室内を飾る大きな壺や一組の飾り物が求められた。外国の器形、紋章、注文意匠への対応は、輸出が単なる販路拡大ではなく製品開発でもあったことを示す。[S18・S23]

中国磁器の代替需要は機会だったが、供給能力、品質、注文への対応がなければ市場は獲得できなかった。後の中国磁器の復帰も、直ちに全輸出が終わったことを意味しない。競争の中で金襴手などの商品が展開した。[S18・S20]

### ヨーロッパへの影響

V&Aは柿右衛門系の意匠がマイセン、シャンティイ、チェルシー、ボウなどに模倣されたことを紹介する。日本磁器は鑑賞・収集の対象であり、欧州製陶のデザイン上の参照先でもあった。ただし「有田焼がヨーロッパの磁器製法を発明させた」という技術因果までは、この資料から言えない。[S23・S24]

## 8. 柿右衛門

酒井田柿右衛門は歴代の作り手の名であり、柿右衛門窯は現在も続く。一方、美術史上の「柿右衛門様式」は、必ずしも柿右衛門家だけの製品に限定されない。V&Aも複数の有田の工房が関わるカテゴリーとして説明する。[S23・S25]

**赤絵の起源**：文化庁の説明自体が、初代による日本初の上絵付成功を「伝えられる」と表現する。1640年代の色絵発展と、「初代一人が特定日に発明した」という主張を分ける。柿の実の色から命名されたといった逸話を使う場合も、伝承と明示し、技術史の証拠にしない。[S26]

**濁手（にごしで）**：温かみのある乳白色の素地。文化庁は家伝の土合帳に基づく泉山陶石などの配合を説明する。透明釉を掛けた普通の白磁すべての別名ではない。柿右衛門様式には染付と色絵を併用するものもあり、「青があるから柿右衛門ではない」と判定できない。[S26・S27]

**継承の実態**：濁手は一度衰え、十二代・十三代が1953年に復興したと財団は記す。文化庁DBでは技術の指定は1971年、保持団体の認定は1976年。両年は矛盾ではなく制度上の出来事が異なる。調査時の窯の当主は十五代。[S26・S28]

記事では「400年間すべて同じ技法を途切れず守った」という固定像より、家伝・復興・職人集団による継承として扱う。[S28]

## 9. 鍋島との関係

鍋島焼は、佐賀藩の藩窯で、将軍家などへの献上を主目的として作られた高品質の磁器。広い商業市場向けの伊万里と、生産目的・管理のあり方が異なる。一方、有田周辺の技術・職人と無関係な別世界でもない。[S29]

伊万里市の説明では、1650年代に有田の岩谷川内で献上品が作られ、1660年代に大川内山の日峯下へ移り、延宝期（1673〜1680）に藩窯体制が整う。単一の「移転年」だけで全過程を置き換えない。1870年に藩窯は廃止された。[S29]

大川内山は現在の伊万里市にあり、「伊万里」はここでは現代の地名でもある。**有田という生産地域、伊万里という港由来の広い呼称、鍋島という藩窯製品**を分けると理解しやすい。記事本体では短い補足欄とし、別記事候補にする。[S13・S29]

## 10. 原料と製造工程

泉山は成立・量産化を考える重要資源だが、現在の有田焼を「全品が泉山陶石製」と説明してはいけない。佐賀県の工程紹介は泉山・天草の陶石を挙げ、現代の窯元には天草陶石の使用を明示する例がある。原料の配合は製品・工房で異なり、泉山の使用率は今回確認できていない。[S02・S30・S32]

| 工程 | 要点 |
| --- | --- |
| 陶土づくり | 陶石を砕き、水簸などで調整し、脱水・練りを行う。原料採掘と製土は別工程 |
| 成形・乾燥 | ろくろ、型を使う方法など。現代は製品と数量に応じて選択 |
| 素焼き | 成形品を焼いて扱いやすくし、下絵・施釉につなぐ |
| 下絵 | 呉須などで文様を描く。線描きと濃みなどの仕事がある |
| 施釉・本焼成 | 釉を掛け、高温で磁器として焼き締める。染付はここで基本的に完成 |
| 上絵付け・上絵焼成 | 本焼した釉面に色を置き、より低い温度で焼き付ける。金彩等で追加の焼成をする製品もある |

工程表の出典：[S30・S31・S33]。全製品が全工程・同じ順序の加飾を持つわけではない。

**温度は代表例**：佐賀県の紹介では素焼き約900℃、本焼成約1300℃。同県の工芸紹介資料は上絵焼成720〜830℃を示す。一方KIHARAの製造紹介には上絵約900℃の説明がある。素地、釉、絵具、窯・焼成条件によるため、一つの固定温度を産地全体の規則にしない。[S30・S33・S34]

**九谷焼との比較**：双方に磁器素地・施釉本焼・上絵再焼成という共通点がある。有田だけが磁器で九谷は陶器、という対比は誤り。九谷は上絵の表現で紹介されることが多いが、有田にも高度な色絵がある。将来の工程比較では、特定の窯元の実例同士を比較する。[S30・S47]

## 13. Buying Guide用情報

### 選び方（編集提案）

1. 最初に用途、重さ、縁の口当たり、重なり、高台、収納寸法を確認する。日常用なら買い足しや機器対応も聞く。
2. 作家物・窯元物・産地商社のブランドは、単純な品質順位ではない。誰が形を設計し、どこで成形・焼成・加飾したかを聞くと、分業の価値が分かる。[背景：S15・S31・S39]
3. 柿右衛門などの高価格品は、様式名だけで判断せず、製造元、作者表記、濁手かどうか、箱・証明・用途を確認。「柿右衛門様式」だけでは柿右衛門窯製品の証明にならない。[S23・S25・S26]
4. 手描きと転写は加飾方法の違い。転写を偽物と扱わず、手描きとの併用も含め販売者に確認する。均一さや価格だけで製法を断定しない。[工程・取扱いの参照：S33・S56]

### ケア：商品説明を優先

| 項目 | 記事で使える慎重な案内 |
| --- | --- |
| 電子レンジ | 「磁器だから全部可」としない。香蘭社は対応表示のない食器の使用を認めていない。金銀彩を含む品は特に個別表示を確認 |
| 食洗機 | 絵具・金彩・転写・形状等で条件が異なる。KIHARAは赤絵・転写などに制限を示すが、他社全製品へ一般化しない |
| 洗剤・スポンジ | 柔らかいスポンジとメーカー指定の台所用洗剤。中性洗剤を基本案にする場合も、当該製品への適合を確認。香蘭社の表記は「台所用合成洗剤」で、中性限定とは書いていない |
| 金銀彩 | 強い摩擦や機器使用、漂白剤に注意。漂白剤の種類までメーカーごとに指示があるため、一律の家庭処置を勧めない |
| 保管 | 器同士の接触を避け、必要に応じ当て紙を挟む。洗浄後は十分乾かす運用を提案 |
| 熱・衝撃 | 急熱急冷を避ける。電子レンジ可とオーブン・直火可は別条件 |

## 14. 九谷焼との関係

### 三つの問いを分ける

1. **九谷の土地に近世の窯が存在したか**：石川県は九谷磁器窯跡を紹介し、生産関連遺跡として位置づけている。古九谷作品の帰属論があるからといって、窯跡の存在まで否定しない。[S50]
2. **後藤才次郎が有田で学んだか**：石川県の文化財解説は、藩命で有田に学んで九谷開窯に関わったという伝統的説明を「はじまりとされている」と記す。今回、本人の修業を直接証明する同時代記録までは確認できていない。[S47]
3. **美術品として古九谷と呼ばれてきた作品はどこで作られたか**：有田の山辺田窯・関連遺跡では、古九谷様式に対応する素地や色絵資料が検討され、有田生産を支える考古学的根拠となっている。単なる文様の類似だけの説ではない。[S48・S49]

**資料の説明の違い**：加賀市の九谷焼美術館は、九谷での17世紀の開窯と地域の継承史を中心に説明する。有田町資料館は、古九谷という分類が作られた経緯と有田の出土資料を重視する。扱う対象の違いもあるため「どちらかの町の説明が全部誤り」と処理しない。[S48・S58]

有田側の出土資料解説には、九谷側の窯道具・色絵の特徴から1650年代前半の山辺田との技術的関係を考える解釈がある。ただし、これだけで後藤才次郎という個人の移動や、あらゆる古九谷作品の生産地が確定するわけではない。[S59]

**記事での暫定表現方針**：九谷と有田には初期色絵磁器をめぐる深いつながりがあり、古九谷と呼ばれてきた作品群には有田生産を支持する重要な発掘成果がある。一方、個別作品の帰属、九谷古窯の役割、人物伝承は論点を分けて扱う。既存の九谷記事と照合する際も、この区別を維持する。

## 16. 記事で使えそうな重要ポイント

以下は**編集上の仮説**であり、章ごとの出典を組み合わせて検証する。

- **中心テーマ案：「土地の資源を、移動してきた人の技術と世界市場への接続が産業に変えた」**。資源→加工技術→職人と制度→物流→注文とデザイン、という順で因果をつなぐ。
- **誕生と量産化を分ける**。1610年代の磁器成立と、泉山利用・窯場再編による集積を分けると、英雄一人の話から地域産業史へ進める。
- **豊かな資源だけではなく、制約への対応を見る**。水の利用、薪の不足、職人の統制は、自然条件を社会がどう組織したかを示す。
- **港の名が産地の名になった**。Arita／Imariを混同しやすい点そのものが、製造と流通の違いを説明する入口になる。
- **注文が器を変えた**。中国の意匠、欧州の器形・室内装飾、国内食器を並べると、伝統を国際的な応答の歴史として描ける。
- **現在も一人では作らない**。製土・型・成形・絵付け・焼成・商社・デザイナーというつながりを、現地訪問と買い方へ接続できる。
- **九谷への橋渡しは「色絵のネットワーク」**。産地の優劣や一方からの単純な借用ではなく、技術と作品が移動する歴史として補足する。

将来の記事で優先して確認するもの：初期磁器・泉山の年代研究の発掘報告原文、古九谷の最新展覧会図録、VOC記録と中国商人の交易研究、比較可能な最新産業統計。今回のメモをそのまま確定稿にしない。
